# 도쿄돔 사진 검수 3차

사용자가 지정한 빨간 블록과 시안 펜스 윤곽을 팬 제작 상세 좌석표의 정원보다 우선했다. G04/G46은 유지하고 G03/G47을 제거했다. 수정 G구간은 24개 블록, 526석이며 번호는 임시 모델 식별자다. 공식 번호·수용 인원으로 취급하지 않는다.

- 모든 G블록의 열은 위 A블록의 열과 평행하다. 블록 경계와 계단은 인접 A좌석 가장자리의 중점을 7개 열에서 추적해 구한 통로 축을 연장한다. 검은 패딩 의자를 사용한다.
- 홈 쪽 G14/G15는 얕은 직사각형에 가깝게 유지한다. G10/G09 앞 윤곽은 깊은 G08 쪽으로 완만히 이어지고, G04 쪽은 A03 터널 외측 문설주까지 한 줄로 좁아진다. 각 블록마다 펜스를 안으로 꺾지 않는다.
- 평행 열과 사선 폴 끝단 펜스 사이의 삼각형 여유 바닥은 의도된 형태다. 중앙 구간 앞줄-펜스 거리는 1.3m 이내, 폴 끝 G04/G05 및 대응편은 2.6m 이내로 검사한다.
- 배터스 아이의 큰 경사판을 제거했다. 현대 전광판 아래 중앙의 단차 있는 돌출부, 수직 차폐체, 양옆의 깊이 있는 닫힌 방을 구성했다. 방 뒤의 외야 복도 통행을 확보했다.
- 외야 입구 뒤를 가로막던 별도 건물 외벽을 연결 복도 바깥으로 확장했다. 입구를 끝까지 통과한 뒤 복도로 꺾이는 경로도 검사한다.
- 발코니 방의 복도 쪽 벽, 문틀, 열린 문짝과 손잡이를 추가했다. 서비스 계단까지 실제 복도에서 진입하는 연결 바닥과 뒷벽 개구부를 만들었다. 계단실 측벽·경사진 천장으로 잘린 슬래브 끝을 마감했다.
- 1층 후면 천장은 발코니의 실제 바닥·방 윤곽 아래까지 연결하고 계단 머리 공간을 절단했다. 발코니 양끝 상부 벽은 전광판 뒤로 이어지며 그 아래의 천장을 생성한다. C2→C3 계단의 머리 공간 개구부는 남겨 두며, 그 바깥으로 기존 슬래브 아랫면 일부가 보인다. 회색 앞벽 하부의 과도한 콘크리트 띠와 익사이트 뒤쪽 펜스 높이의 급격한 전환을 정리했다.

검증: 독립 데이터 감사에서 번호 불일치·중복, 잘못된 단 폴리곤, 바닥 없는 좌석, 겹친 좌석, 좌석과 기둥의 충돌이 모두 0건이다. G구간을 제외한 좌석 집합은 기존 상세표 예외 규칙을 유지했다. 모든 G블록은 A열 방향과 2.5도 이내이며 한 블록 안의 열 방향 변화는 1도 이내다. 실제 앱 Walker의 계단·입구·연결 복도·G통로 177개 보행 검사, 기하 회귀 검사 7개, 프로덕션 빌드를 통과했다.

검수 이미지는 앱에서 카메라만 이동해 촬영한다. 내부 촬영에서는 해당 카메라 위치로 앱의 기존 조명 판정도 갱신한다. 촬영을 위해 구조물을 숨기거나 옮기지 않는다.
