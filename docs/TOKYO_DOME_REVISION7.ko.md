# 도쿄돔 7차 구조 검수

- [x] 3층 끝의 독립된 높은 판 제거
- [x] 3층 앞면의 회색 띠·유리·난간 단면을 그대로 90도 돌려 끝단 마감
- [x] 4층 앞면과 끝단의 재질·단면 통일
- [x] 추가했던 4층 끝 옆 박스형 벽과 3층 발코니 천장 판 제거
- [x] 앞면과 끝단을 한 부재로 연결하고 모서리 두께·난간 접합부 닫기
- [x] 전광판 뒤 입체 구조의 앞면을 LED 곡률과 동일하게 전진
- [x] 뒤쪽은 기존 외피까지 유지·확장해 기둥 뒤 좌석 전체의 천장 확보
- [x] 돔 가로선의 위상과 처짐을 초록색 주석 및 실사에 맞춰 조정
- [x] 홈·외야·1루·3루 네 방향에서 같은 지붕 격자를 각각 촬영·검수
- [x] 양쪽 3·4층 끝단, 천장, 돔 가로선을 각 시점에서 렌더로 검수

3층 끝판을 4층 끝판으로 단순 교체하는 대신, 각 층의 기존 앞면 단면을 끝단까지 연속으로 사용한다. 끝단은 해당 좌석 바닥 높이를 따라간다. 펜스 모서리는 동일 꼭짓점과 마이터를 공유하며, 튜브 난간도 직각 접점에서 연결한다.

전광판 뒤 구조는 LED와 같은 곡선식을 사용하고 0.4m 뒤에 둔다. 바깥쪽 경계는 외피까지 닿도록 확장하므로 앞면을 당겨도 뒤 좌석의 천장 깊이가 줄지 않는다. 양 끝은 기존 발코니 상부 벽과 이어진다.

가로선은 반 칸 간격만큼 위치를 조정하고, 각 세로 케이블 사이에서 완만히 처지도록 한다. 선만 옮기지 않고 천의 굴곡·고정구·등 위치도 같은 좌표계를 사용한다. 세부 깊이는 사진 비례 조정이다.

공식 발코니 360°의 1·34번 통로 끝(320·87 지점), 상단 360°의 381·444 지점, 현대 전광판을 포함한 발코니 측면 사진과 사용자 추가 사진을 대조했다. 최종 사용자 지시에 따라 별도로 추가했던 발코니 천장 판과 그 위 박스형 벽은 제거했다. 전광판 뒤의 외야 입체와 13.6m 아래 면은 이 추가 판과 별개의 구조다.

돔 격자는 한 면에만 붙인 도형이 아니라 전체 지붕에서 공유하는 세계 좌표로 그린다. 네 방향의 선·처짐·고정구를 같은 방식으로 확인한다. 지붕 구조의 직교 케이블과 링 형태는 竹中工務店 저자의 1989년 자료 Fig.2 및 日建設計 설명도 대조했다. 사진 비례로 맞춘 가로선 세부 치수는 실측값이 아니다.

검수: 실제 앱 렌더 16개 시점, 이동·충돌·천장 검사 193개 통과. 중앙 외야 기둥 뒤 17열 이상 688석의 머리 위 천장을 개별 광선으로 확인했다. 최종 사용자 지시대로 별도 발코니 천장 판과 박스 벽을 제거한 상태에서 검수했다. 회색 띠의 닫힌 모서리와 세 방향 구멍 검사, 기존 구조 회귀 검사 7개, 독립 좌석·기둥 감사 및 앱 빌드도 통과했다.
