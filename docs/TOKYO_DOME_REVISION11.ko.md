# 도쿄돔 11차 천장 검수

- [x] 구조 도면 Fig.2의 8.5m 케이블 간격을 전체에 일정하게 적용
- [x] 벽에서 가까운 가로 구간을 5칸, 안쪽을 7·9·11·13칸으로 구성
- [x] 가로선 바깥 구간을 제외해 배치를 만들며 국소적인 간격 압축은 사용하지 않음
- [x] 기존 도면 기반 지붕 외곽·기울기·큰 곡면 유지
- [x] 제공된 공연 사진과 내부 광각·근접 사진에 맞춰 캔버스 처짐·봉제선 곡률·무광 직조·작은 원형 부품 조정
- [x] 2열 조명 뱅크 4개, 소형 장비 케이지 1개와 지지 와이어 20개 추가
- [x] 각 장비의 지지점을 실제 격자 케이블 교차점에 연결
- [x] 네 방향 벽 연결·상부 좌우·장비 근접·공연 상태 렌더 검수
- [x] 일정한 간격·보행 회귀·장비 지지 검사와 빌드 확인

[자료 목록](references/tokyo-dome-review-11-sources.json)의 내부 사진 4장을 새로 확보해 광각 전체, 폴 옆 상향, 케이블·매달린 장비 근접 장면을 확인했다. 공식 내막 근접 사진과 공식 4층 파노라마 양쪽, 사용자가 마지막에 제공한 공연 중 내부 사진도 함께 대조했다.

격자 간격은 수정 전 앱의 약 7.754m에서, 구조 자료 Fig.2에 표시된 8.5m로 바꾼다. 주 케이블 14개씩을 기준으로 중앙 13칸의 폭을 잡으며, 모든 구간은 같은 간격을 사용한다. 벽 쪽에서는 이 격자의 가로선 구간만 제외해 사용자 지정 5→7→9 배치를 만든다. 가로선을 벽 쪽으로 압축하는 좌표 변형은 없다.

큰 지붕 곡면은 기존 도면 기준을 유지한다. 작은 처짐 0.65/0.12m와 봉제선의 0.5m 휘어짐은 내부 사진 비례로 조정한 시각적 추정값이다. 미세한 직조·회백색 무광 재질과 원형 부품은 격자의 위치를 바꾸지 않는다.

추가 조명은 6개씩 2열의 원형 렌즈와 금속 프레임, 네 지지 와이어를 갖는다. 중앙 소형 장비는 열린 금속 케이지와 아래쪽 원형 장치로 표현했다. 조명은 기존 객석 조명 재질을 공유해 공연 중 함께 어두워진다. 장비의 정확한 설치 목록·위치는 확정 도면이 없으므로 사진을 참고한 배치 추정이며 실측 복원으로 주장하지 않는다.

좌석·펜스·전광판·보미토리 데이터는 변경하지 않는다. 앞선 4층 조명 고정, 보미토리 높이, 초록색 공연 바닥은 유지한다. 천장 재질과 장비는 일반 도쿄돔과 360도 모드에서 함께 사용한다.

최종 검수는 현재 앱 화면 10장과 정투영 진단 1장으로 진행했다. 실제 앱 회귀·장비 검사 201개, 별도의 네 방향 격자·지지점 검사, 기존 펜스·조명 고정 검사와 프로덕션 빌드가 통과했다. 공연 화면은 실제 재생 API의 chorus, 객석 조명 0 상태다.

정투영 진단에서 벽 쪽 다섯 가로선의 화면 좌표는 579.636·554.909·530.182·505.455·480.727px로, 간격은 모두 약 24.727px다. 지면 투영 간격은 8.5m로 일정하며, 가까이서 올려다본 화면에서 멀어지는 선이 촘촘하게 보이는 것은 원근 효과다. 진단 화면은 위에서 내려다본 케이블 배치 확인용이다.
