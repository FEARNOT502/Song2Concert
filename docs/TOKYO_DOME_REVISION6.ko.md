# 도쿄돔 6차 구조 검수

- [x] 정면·양쪽·위쪽·출입구·구덩이·천장 시점으로 촬영해 확인

기존 발코니 끝벽의 두 끝점에서 얻은 약 6.24m 단면 폭을 유지하고, 밑면 높이 13.6m로 둘러 잇는다. 얇은 곡면 벽과 별도 천장을 덧대던 5차 방식을 대체한다. 입체 구조의 밑면이 외야 뒤 좌석 위 천장이다.

RYOBI 벽은 F11 마지막 열 뒤에 의자 여유 공간만 두고 세운다. 벽은 그 뒤 바닥에서 전광판 아래까지 이어지며, 뒤쪽과 옆면도 C2 콘코스 앞까지 닫는다. 중앙 화면과 RYOBI 벽 사이 흰 틈에는 녹색 측벽을 세운다.

전광판은 2022년형 가로 밴드와 중앙 하단 화면을 유지하며 전체를 약 2.5m 후퇴시킨다. 화면·프레임·차폐체·지지 연결부를 함께 맞춘다. 크기와 후퇴량은 사진 비례 추정이다.

공식 1층 파노라마 1053·288과 `modern-25` 사진에서 RYOBI 바깥의 좁은 출입구를 확인했다. 별도 출입구나 계단 형상을 만들지 않고, 기존 F 외야 보미토리 데이터를 그대로 복사해 폭만 4m에서 2.4m로 줄였다. 입구 높이·통로 길이·파라펫·뒤쪽 마감·콘코스 연결 방식은 기존 보미토리와 같다. 좌석 통로에서 새로 올라가는 독립 계단을 추가하지 않는다. 새 두 곳을 포함한 외야 보미토리 10개는 하나의 C2 콘코스를 공유한다.


## 확인 결과

정면·양쪽·위쪽·F11 접합부·구덩이·발코니 끝·외야 뒤 좌석 천장 등 16장의 화면을 확인했다. 중앙 하단 화면과 RYOBI 벽 사이에 보이던 흰 틈은 초록색 측벽으로 닫았다. F11 측면의 불필요한 여유를 약 0.44m 줄였고, 전후 위치는 공식 파노라마의 구덩이 깊이와 마지막 열 뒤 벽 위치를 기준으로 다시 배치했다. 93개 좌석 ID를 유지한다.

구덩이의 넓이는 실측값이 아닌 사진 비례 추정이다. 앞 외야 펜스를 넘어가지 않게 잘랐고, 내부 콘크리트를 어둡게 처리하며 윗부분은 녹색으로 마감했다. 위를 막는 면은 없다. 구덩이 중앙을 내려다본 광선은 바닥 높이 0.35m까지 도달한다.

보행·개구부·천장 검사 192개 실패 0, 기하 검사 7개 통과, 프로덕션 빌드 통과. 기둥 뒤 좌석 위 네 지점의 상향 광선이 모두 13.6m 높이의 입체 벽 밑면에 닿는다. 데이터 검사에서 좌석 번호 불일치·중복·미지지 좌석·잘못된 단·기둥과 의자 충돌이 모두 0건이다. 새 좁은 보미토리 두 곳을 기존 외야 보미토리와 같은 구조로 양방향 통과하고, 뒤 C2 콘코스도 계속 통과할 수 있는지 확인했다. 후퇴한 전광판에 맞춰 실제 렌더 시 이동하는 지지 기둥 위치도 별도로 대입해 의자 충돌이 없는지 확인했다.
