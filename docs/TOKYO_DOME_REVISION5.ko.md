- [x] F11을 F12 계단 통로에 붙이고 93개 좌석 ID 유지
- [x] F10 초록 단과 배터스 아이 중앙·양쪽 구조를 관객 시점에서 복원
- [x] 익사이트 바로 옆 내야 펜스 국부 높이 조정
- [x] 익사이트 끝단 상승 경사를 소폭 증가
- [x] 발코니 끝의 보이는 벽 면을 단일 연속 벽으로 전광판 뒤까지 연결
- [x] 배터스 아이 정면·양쪽 사선·F11 상부·상부 벽을 각각 촬영해 확인

## 실사 근거와 반영

[도쿄돔 공식 1층 파노라마](https://my.matterport.com/show/?m=hKaQSvco93D)의 1053·1054·1260·288 지점을 대조했다. 2023년 스캔이므로 실측 도면으로 취급하지 않는다. 1054 정면과 1260 측면에서 F11 앞의 개구부가 위로 열리고, 그 안으로 콘크리트 벽이 내려가는 구조임을 확인했다. 288에서는 RYOBI 광고실과 F11 뒤쪽 바닥, 옆 계단의 관계를 확인했다. 기존 현대식 전광판 사진(`modern-25`)도 함께 비교했다.

F11은 F12 앞 10열의 통로 경계를 직선으로 맞춘 뒤 좌석과 지지 바닥을 함께 옮겼다. 좌석의 원래 열·번호 93개와 좌석 방향은 유지한다. 인접 좌석 중심선 간 약 1.94m를 확보해 양쪽 바닥 여유와 약 1.1m 통로에 대응시켰다. F11 바닥과 단면은 녹색으로 마감한다.

F11 앞 개구부에는 덮개나 계단이 없다. 좌석 단·녹색 단·바닥을 위아래로 잘라 내부에 콘크리트 옆면과 아래 바닥을 만들었다. 처음 촬영에서 개구부가 외야 펜스를 가로지르는 문제가 보여, 전체 개구부를 펜스 뒤로 제한했다. 앞쪽 가장자리 높이는 약 3.1m, 뒤쪽은 F11 앞 단에 맞췄다. 폭 약 7.2m, 바닥 높이 0.35m와 깊이는 사진 비례 추정이며 실측값이 아니다.

이전 수정에서 차폐체를 지나치게 뒤로 옮겨 기존 외피에 가렸던 문제를 수정했다. 중앙 차폐체를 하부 LED 바로 뒤로 복원하고, F10 녹색 단과 양쪽 광고실을 입체적으로 다시 보이게 했다. F11을 옆 통로로 옮기면서 LED 아래에 겹쳤던 좌석 포켓을 비웠다. 광고실 하단에는 가로 개구부를 두고, 뒤 콘코스를 막지 않도록 깊이를 조정했다. 전광판 아래의 별도 납작한 돌출 판은 없다.

발코니 연결 벽은 원래 보이는 끝 면 대신 바깥 반환부를 거쳐 이어지던 방식을 수정했다. 두 기존 벽과 전광판 뒤쪽 곡선을 한 개의 연속 벽 스트립으로 만들고 바깥 반환 면을 제거했다. 실제 외피보다 안쪽으로 제한해 연결 벽이 외피에 가려지지 않도록 했다.

익사이트석 홈 쪽에 바로 붙은 내야 펜스는 약 1.35~1.55m로 낮추고 12m에 걸쳐 포수 뒤의 2.2m 높이로 연결했다. 앞 좌석 바닥의 높이 보정도 A16~A19·A31~A34에서 점진적으로 바뀌도록 맞췄다. 익사이트 끝단은 기존보다 0.1m 정도 더 올라가도록 소폭 조정했다.

## 검증

최종 모델의 보행·개구부 검사 178개 실패 0, 기하 검사 7개 통과, 프로덕션 빌드 통과. 구덩이 중앙을 위에서 내려쏜 광선이 중간 덮개 없이 바닥까지 도달하는지도 실제 앱의 충돌 모델로 확인했다. 독립 데이터 검사에서 번호 불일치·중복·바닥 없는 좌석·잘못된 단 폴리곤·기둥과 좌석 충돌이 모두 0건이다. 정면·좌우·위쪽 배터스 아이와 구덩이·F11 접합부·양쪽 상부 벽·펜스 등 12장의 최종 렌더를 확인했다. 4차 기록 중 F11의 덮인 터널 치수와 연결 벽 생성 방식은 이 문서의 내용으로 대체한다.
