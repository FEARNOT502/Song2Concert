# 도쿄돔 12차 삼각 패널 수정

이후 발견된 꼭짓점·경계선 누락은 [13차 수정](TOKYO_DOME_REVISION13.ko.md)에서 보완했다.

- [x] 네 모서리의 삼각 패널 내부에서 반복 처짐·굴곡 음영 제거
- [x] 처짐이 사라지는 전환 구간을 삼각 패널 바깥의 격자 쪽으로 이동
- [x] 삼각 패널 경계를 곡선 봉제선 좌표에서 분리해 직선 케이블 기준으로 통일
- [x] 삼각 패널의 얇은 이음선도 굽히지 않은 좌표에서 계산
- [x] 네 방향 근접 화면과 같은 카메라의 수정 전후·공연 상태 확인
- [x] GPU에서 삼각 영역 처짐 0 확인, 기존 격자·장비 검사와 빌드 확인

기존에는 처짐이 삼각 패널 안으로 3.5m 들어간 뒤 사라졌고, 패널 표시 경계에는 휘어진 봉제선 좌표가 쓰였다. 형상·법선·음영의 적용 범위가 달라 삼각 영역 경계에 물결이 남을 수 있었다.

같은 삼각 영역 함수를 형상 변위·법선·굴곡 음영에 사용하며, 패널 내부에서는 반복 처짐의 가중치가 정확히 0이다. 격자 쪽에서 부드럽게 전환해 경계에 단차가 생기지 않게 한다. 8.5m 간격과 벽 쪽 5·7·9칸 배치는 유지한다.

검수: 네 방향 근접 화면 4장, 같은 카메라의 수정 전후 2장, 상부 광각 1장, 실제 공연 재생 1장을 확인했다. GPU에서 네 삼각 영역의 4,096개 좌표가 모두 처짐 가중치 0으로 확인됐으며, 실제 앱 검사 202개·기존 격자 및 장비 지지 검사·프로덕션 빌드가 통과했다.
