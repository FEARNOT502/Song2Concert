# 도쿄돔 13차 삼각 패널 꼭짓점·경계 수정

- [x] 네 삼각 패널의 꼭짓점을 케이블 교차점에 고정
- [x] 꼭짓점에서 외곽으로 이어지는 두 경계선을 별도로 표시
- [x] 경계선을 벽 쪽 5·7·9칸의 선 생략 처리에서 분리
- [x] 내부 격자·굴곡·색 음영에 같은 삼각 영역 적용
- [x] 네 방향 근접·수정 전후·공연 화면에서 꼭짓점과 두 변 확인
- [x] GPU에서 꼭짓점·양변·내부 차단 및 처짐 0 확인, 기존 격자·장비 검사와 빌드 확인

삼각 패널은 중심 기준 (±55.25m, ±55.25m)의 교차점에서 시작한다. 이 꼭짓점에서 x 또는 z 좌표를 고정한 두 경계 케이블이 외곽 링까지 이어진다. 일반 격자 선을 생략하는 마스크를 이 경계 케이블에 적용하지 않는다.

삼각 영역의 표시 경계와 내부 격자 차단은 같은 거리 함수로 계산한다. 패널의 색 음영을 바깥 격자 쪽으로 확장하지 않으며, 반복 처짐은 경계에 도달하기 전에 사라진다. 경계의 선 폭만 화면 픽셀 기준으로 부드럽게 처리한다.

검수: 네 방향 근접 4장, 같은 카메라 수정 전후 2장, 상부 광각·공연 상태 각 1장을 확인했다. GPU에서 꼭짓점 4개·양변 504개 지점·내부 격자 차단 4개 지점과 처짐 0인 4,096개 좌표를 확인했다. 실제 앱 검사 203개·기존 격자와 장비 지지 검사·프로덕션 빌드가 통과했다.
