# 도쿄돔 8차 검수

- [x] 양쪽 발코니–외야 벽의 연결 면을 한 부재로 연결하고 하단도 13.8m 수평선으로 통일
- [x] 발코니 끝면 하단을 앞면과 같은 높이로 닫아 노출된 단차 제거
- [x] RYOBI 광고 벽·패널과 중앙 하단 화면·지지대를 새 전광판 높이에 맞춰 조정
- [x] RYOBI 글자 패널의 자체 발광 재질과 환경 반사 제거
- [x] A02 철망을 조명을 받는 실제 가는 부재로 바꾸고 자체 발광·환경 반사 제거
- [x] 포수 뒤에 높게 덧댄 빈 콘크리트 띠 제거
- [x] 정지·재생 상태에서 재질과 실제 렌더 검수

높이 기준은 기존 발코니 앞면 바닥 15m에서 앞 띠 두께 1.2m를 뺀 13.8m다. 긴 전광판의 높이 7.5m와 중앙 하단 화면 높이 5.4m는 유지하고 전체를 0.4m 올린다. RYOBI 벽 상단과 광고 패널도 이 기준을 따른다. 사용자 지시에 따라 경사진 연결부 대신 수평 하단으로 연결한다.

벽의 앞면을 별도 얇은 판과 두꺼운 입체의 경계에 따로 두지 않고, 좌우 발코니 벽부터 전광판 뒤까지 같은 단면의 한 면으로 만든다. 별도 발코니 천장 판은 추가하지 않는다.

RYOBI 광고는 조명에 반응하는 무광 재질로 바꾸며, A02 철망도 고정 밝기의 선 재질 대신 실제 가는 메시 부재로 표현한다. 두 재질 모두 발광색은 검정, 환경 반사 강도는 0이다. 공연 조명이 비출 때의 자연스러운 확산 조명은 남는다.

포수 뒤 빈 단은 좌석 데이터가 아니라 펜스 높이로 덧댄 별도의 콘크리트 띠였다. 이 띠를 제거하며 좌석·기존 바닥·초록색 패딩 펜스는 유지한다.

치수는 모델 좌표와 사진 비례에 따른 조정이며 실측값은 아니다.

검수: 실제 앱 이동·충돌·천장·재질·높이 검사 195개 통과. 양쪽 벽 연결 면·하단 검사와 모서리 광선 검사, 구조 회귀 검사 7개, 독립 좌석·기둥 감사 및 앱 빌드 통과. 렌더 9개 시점을 확인했고 재생 장면은 실제 재생 API로 공연 모드(객석 조명 0, chorus)에서 촬영했다. 포수 뒤 띠를 제거한 중앙의 기존 바닥 높이는 약 1.362m다.
