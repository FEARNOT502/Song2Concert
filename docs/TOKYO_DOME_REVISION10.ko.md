# 도쿄돔 10차 검수

- [x] 떠 있던 공연 조명을 실제 4층 앞 펜스 위로 이동
- [x] 펜스 상단에 닿는 받침판과 양면 고정 브래킷 추가
- [x] 4층 보미토리 14곳의 좌석 단 위 벽 돌출량을 약 1m에서 0.5m로 축소
- [x] 보미토리 바닥·입구 폭·천장·좌석 위치 유지
- [x] 공식 사진과 파노라마를 근거로 천장 캔버스 수정 계획 작성
- [x] 조명 접합부·양쪽 보미토리·공연 상태 렌더 검수
- [x] 실제 이동·충돌·지지면 검사와 앱 빌드 확인

조명 배치는 예전 `rim` 선과 고정 17m 높이를 사용하던 방식을 실제 D층 앞 펜스의 경로·상단 높이를 따르는 방식으로 바꾼다. 6cm 받침판은 펜스에 닿고, 위로 향한 조명 베이스는 그 판 위에 바로 닿는다. 펜스 양면에 짧은 고정 다리를 추가한다. 낮음/일반 품질의 10개/18개 배치 모두 펜스 위에 놓이는지 광선으로 확인한다.

보미토리는 E층의 열린 절개를 두르는 벽의 앞·뒤 상단만 0.5m 낮춘다. 통로 천장 높이와 계단·좌석·다른 층의 보미토리는 기존 데이터를 유지한다.

천장은 [내막 재현 계획](TOKYO_DOME_ROOF_CANVAS_PLAN.ko.md)에 정리했다.

검수: 실제 앱 이동·충돌·바닥·조명 접합·보미토리 검사 200개, 10개/18개 조명 위치의 실제 펜스 지지 광선 28개, 독립 좌석·바닥·기둥 감사와 앱 빌드 통과. 7개 시점을 확인했으며 공연 상태는 실제 재생 API의 객석 조명 0, chorus 상태다. 천장 렌더는 계획 비교를 위한 기존 구조 기준 화면이다.
