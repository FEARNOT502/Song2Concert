### 끝난 것

- **1층 A·B 좌석**: 실제 좌석표(`td/td_rows_real.json`)대로 열마다 번호대로 깔았다. 함수는 `td_stand1.lay_real`. 19,548석 중 약 19,200석이다.
  - 좌석 폭은 0.40–0.55 m이다.
  - `DENSE` 블록(A01–A03, A47–A49, B02, B48)은 열 끝까지 0.45 m 간격으로 채운다.
  - `MIRROR_FILL`: A02의 14–19열은 A48의 좌석표로 채운다.
- **3루 테이블석**: B31–B33의 36열 이후를 밝은 파랑으로 칠했다.
  - 생성기 쪽은 `td_stand1.TABLE`이고, 결과는 `td_stands.json`의 B 레벨 `tables`에 들어간다.
  - 앱 쪽은 `dome.js`의 `seatColorAt`가 칠한다.
- **높이**: `td_stand1.fit_rake`가 정한다.
  - 블록마다 곧은 경사이고, 통로 앞뒤 두 구간을 쓴다(뒤가 같거나 가파름).
  - 앞줄은 2.2–4.5 m, 뒤끝은 콘코스 높이(10.6 m)이다.
  - 외야 폴 쪽 4블록(F17–F20, F01–F04)은 블록마다 높이를 따로 맞춘다. 블록 분류는 `outfield_classes`이고, 10열부터 더 가파르다.
- **A01**: `fit_rake`가 정한 경사 대신 F20과 맞닿는 경계를 따라 F20 높이에 맞춘다. 앞에서 12.8 m에서 콘코스 높이에 닿고, 그 뒤 약 5 m는 평평하다. `td_build.py`의 "A01 (and A49) as high as the outfield stand beside it" 블록이다.
- **블록 회전과 사선 구역**:
  - `T1.ROT = {1: 8, 2: 8}`: A01·A02(대칭 A49·A48)의 열을 홈 쪽으로 8° 돌렸다. 돌린 블록은 통로(A/B 사이 보행로) 위치를 원래대로 유지한다.
  - `T1.KINKR`: A02 앞쪽(터널 위치)에서 B02 뒤쪽의 폴 반대편 모서리까지 사선 하나(`_Q0`→`_Q1`)를 긋는다. 그 폴 쪽에 있는 A01·A02·B02 열은 외야 열과 나란하다(방향 `_frA`, 외야 펜스 거리의 기울기). 구현은 `Finger._behind`, `coord`, `coord_xz`, `row_point`, `facing(pt=)`이다.
  - `T1.KINK`는 비어 있다. B02만 20° 꺾던 방식은 이 사선 구역으로 대체했다.
- **A02 터널**(A48에는 없음):
  - 위치는 A02 앞 가운데이고, 폭 3.8 m, 앞 3 m는 바닥까지 뚫렸고 그 뒤는 지붕(약 4.0 m) 아래 터널이다. 축은 A02 맨 윗열과 직각이다.
  - 데이터는 `td_stands.json`의 `tunnels`에 있다. 그리는 쪽은 `stands.js`의 `buildTunnels`(뚫린 통로 + 지붕)다.
  - `dome.js`가 펜스를 입구에서 끊고, 여닫이 두 짝(두께 0.22 m, 옆 펜스 높이), 옆 단 높이를 따라가는 녹색 패딩, 입구 위 콘크리트 슬래브를 단다.
- **익사이트석 G**:
  - 블록마다 필드 쪽 변과 나란한 곧은 열이고 필드를 향한다. 열 수는 블록 라벨대로(1–6)다.
  - 띠는 열 깊이만큼만 남겨 스탠드에 붙였다.

  - 망은 달지 않는다(사용자 지시).

  - 외야는 수평이고 리본 전광판 높이는 하나다. 리본 전광판은 무광 검정이다(반사 때문에 콘크리트처럼 보였다).
  - 포수 뒤는 최소 2.2 m이다.
  - 내야 펜스는 스탠드 앞면 아래로 내려가지 않고, 외야 높이를 넘지 않는다.

## 2. 남은 일 (우선순위 순)

1. **A01·A02·B02 재작업 마무리** (사용자가 마지막으로 보던 부분)
   - A01|A02 통로 뒤쪽의 2.2 m 벽을 줄인다.
     - A02(와 B02의 사선 폴 쪽 부분)도 F20/A01처럼 뒤쪽에서 콘코스 높이에 일찍 닿게 하는 방법이 있다. 사선 구역 안의 열은 외야 열과 나란하니, 구역 전체를 한 높이 함수(외야 열 높이를 이어서)로 맞추는 쪽이 자연스럽다.
     - 사선 구역(`KINKR`) 안에서는 블록별 `fit_rake` 프로필 대신 외야 F20의 열 높이를 `_frA` 방향으로 이어 쓴다. 그러면 구역 경계(사선)에서만 단차가 생긴다.
   - 사선의 위치와 각도를 레퍼런스에 맞춘다.
     - 지금 사선은 `_Q0`(A02 앞 가운데)에서 `_Q1`(B02 뒤쪽, 폴 반대편 모서리)까지다. 사용자 사진에서는 폴 바로 옆 앞쪽(터널 근처)에서 오른쪽 위로 B02 뒤쪽까지 완만하게 올라간다.
     - 사선 앞쪽(아래) 맨 앞 몇 줄은 폴 쪽으로 모이는 부채꼴이다(사용자 사진의 빨간 선).
   - 사용자가 "A02 너무 더럽다"고 여러 번 지적했다. 사선 경계, 터널 주변, 통로에서 단이 깨끗하게 끝나는지 렌더로 확인한다.
2. **익사이트석 뒤 펜스 마감**: 익사이트석 띠의 폴 쪽 끝에서 앞쪽 낮은 펜스가 급하게 꺾인다. 높은 외야 펜스와 깔끔하게 잇는다.
3. **외야 F 실제 좌석수**: 실제는 F01–F20이 1–21열이다(F01·F20은 18열). 지금 모델은 19열에 `lay_curved`로 기하 배치한다. 좌석표 데이터는 `td_rows_real.json`의 F 블록에 있다.
4. **2층 D·E 실제 좌석수**: 데이터는 `td_rows_real.json`(D01–D51, 스카이테라스 포함)과 `td/td_rows_2f.txt`에 있다. 지금은 `td_gen.py`가 기하로 배치한다.
5. 외야 F·2층 재배치가 끝나면 좌석배치도를 다시 만든다:
   ```bash
   ONLY=dome,dome-360 CHANNEL=msedge node scripts/venue-maps.mjs
   ```
6. 확인할 것: `venue-lab/reachcheck.py`, `vomtest.mjs`(걸어서 닿기), 프레임 시간.

## 3. 돌리는 법

```bash
# 생성 (약 4–5분). 출력은 venue-lab/pipeline/td_stands.json
cd venue-lab/pipeline && PYTHONIOENCODING=utf-8 python -u td_build.py > build.log 2>&1

# 앱 데이터로
cd venue-lab && python pipeline/mkdata.py td
sed '3s/^const TD_STANDS/export const TD_STANDS/' venue-lab/src/j0-td-data.js > src/three/venues/td-data.js

# 빌드 확인
npx vite build
```

- `td_build.py`는 `td_stage1.pkl`, `td_rowsA.pkl`(커밋 안 됨, 로컬에 있음)을 읽는다. 없으면 `td_gen.py`, `td_rowsA.py`를 먼저 돌린다.
- 파이썬 패키지는 numpy, scipy, opencv-python, shapely, scikit-image, matplotlib, pypdf이다. `python -I`로 돌리면 사용자 site-packages가 안 보이니 쓰지 않는다.
- 로그에서 볼 줄: `rake fit`, `steps across the aisles`(통로·외야 연결 단차), `1st floor seats by the chart`, `tunnel under A02`, `excite seats laid`.

## 4. 주의

- 폴 쪽(A01/A49, A02/B02, F20/F01)은 단차를 바꿀 때마다 모델링이 잘 깨진다. 렌더로 매번 확인한다.
- `fit_rake`의 `fmax`(4.5 m)는 앞줄 상한이다. 외야 펜스보다 높으면 앞면 콘크리트가 펜스 위로 튀어나온다. 펜스는 외야 높이를 넘지 않는다(사용자 지시).
- 블록을 돌리면(`ROT`) 통로 위치가 움직인다. `fingers_of`가 돌리기 전 위치와 깊이를 지켜 주는데, 이걸 빼면 A02 뒤에 넓은 빈 평지가 생긴다.
- `KINKR`/`KINK` 영역에서는 열 번호가 실제 좌석표 범위를 넘을 수 있다. 그 블록은 `DENSE`에 넣어 빈 단이 생기지 않게 한다.
- `td_stands.json`의 좌석 좌표는 A·B 레벨만 2 cm 단위(`seatScale: 50`)이고 나머지는 10 cm 단위다.
