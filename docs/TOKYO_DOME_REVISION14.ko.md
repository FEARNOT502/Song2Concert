# 도쿄돔 14차 삼각 패널 범위·스탠드 조명

- [x] 첨부 공연 사진 기준으로 두 삼각 패널 사이 세로 패널을 13칸으로 고정
- [x] 삼각 패널 밑변을 외야 약 4블록 폭에 맞춤
- [x] 삼각 꼭짓점을 기존 8.5m 격자 교차점에 유지
- [x] 네 방향의 5·7·9칸 배치, 패널 내부의 처짐·격자 차단 유지
- [x] 계단형 밝은 띠가 새 삼각 꼭짓점에서 끝나도록 방향과 길이 정렬
- [x] 4층 펜스 조명과 고정 브래킷을 일반·360도 모드에서 공통 사용
- [x] 두 모드의 재생 중 빔 방향·색·밝기 갱신 연결
- [x] 외야 블록 표시·네 모서리·수정 전후 화면 대조
- [x] 일반·360도 모드의 조명 근접·재생 화면과 실제 조명 버퍼 확인
- [x] 실제 앱 회귀·GPU 패널 검사, 격자·고정 검사와 빌드 확인

삼각 패널 범위를 두 축으로 분리했다. x축 꼭짓점 사이 110.5m를 8.5m씩 나누어 세로 패널 13개를 만든다. 중심 기준 꼭짓점을 (±55.25m, ±46.75m)로 잡아 8.5m 격자의 교차점에 두며, 양변은 외곽 링까지 이어진다. 밑변 양 끝 사이 거리는 약 23.6m에서 34.5m로 넓어진다. 실제 내부 사진의 외야 약 4블록 폭과 사용자의 기준을 따르는 비례 조정이다.

모델의 외야 후방 블록 폭과 상당 부분 겹치는 범위를 기준으로 오른쪽 F16·F17·F18·F19, 왼쪽 F02·F03·F04·F05이 주로 해당 범위에 들어온다. 양 끝은 블록 일부와 겹칠 수 있다. 이는 블록과 패널의 평면 배치를 비교한 결과이며 사진에서 실측한 치수는 아니다. 최신 사용자 공연 사진의 13개 세로 패널과 양쪽 삼각형을 우선 기준으로 삼았다. 삼각형 가장자리의 얇은 밝은 띠와 원형 부품, 얇은 천 이음선을 표현하며 내부에는 격자 굴곡을 넣지 않는다. 최신 기준은 [14차 자료 목록](references/tokyo-dome-review-14-sources.json)에 기록했다. 기존 사진 자료는 [11차 자료 목록](references/tokyo-dome-review-11-sources.json)의 전체 내부 광각 사진과 공식 4층 파노라마를 다시 대조했다.

4층 펜스 빔 조명은 일반 모드의 무대 분기에만 있었으므로 360도 모드에는 생성되지 않았다. 조명 생성·브래킷·재생 갱신을 공통 모듈로 옮겨 두 모드에 적용한다. 기존 일반 모드의 펜스 위치와 고정 방식, 품질별 10개·18개 수량을 따른다.

검수: 일반 모드 화면 13장(수정 전 비교 1장 포함)과 360도 모드 화면 3장을 확인했다. 두 모드 모두 10개 조명 본체와 고정 브래킷이 실제 모델에 있고 재생 중 10개 모두 빔 버퍼에 양의 밝기를 전달한다. 품질별 10개·18개 고정 및 재생 검사, 네 방향 격자·외야 4블록 범위 검사, 실제 앱 회귀·GPU 검사 203개와 빌드가 통과했다.
