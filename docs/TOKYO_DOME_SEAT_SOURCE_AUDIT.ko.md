# 도쿄돔 좌석표 신뢰도 재확인

## 결론

현재 사용한 상세 좌석표는 **팬 제작 자료**다. 공식 좌석 배치도와 교차 확인했지만, ‘2026년 현장의 모든 좌석 번호와 수량이 공식적으로 검증됐다’고 말할 수는 없다. 특히 좌석표의 블록 도형은 실제 미터 단위 평면도가 아니다. 이 도형으로 익사이트석의 폭·위치를 결정하던 방법은 폐기했다.

익사이트석은 공식 배치도의 **26개 블록별 시작·끝 열과 시작 번호가 상세표와 일치**한다. 상세표의 총 670석은 모델에서 빠짐없이 재현하되, 이 총수를 공식 수용 인원으로 표시하지 않는다. 매 열의 마지막 번호는 공식 전체 배치도만으로 확인할 수 없다.

## 남은 불일치

- B22는 상세표 27–40열, 공식 전체 배치도 27–46열로 차이가 있다. 특수·취재석 등의 배치인지 확인되지 않아 번호를 추정 추가하지 않았다.
- A01/A49에는 상세표 자체에 22·23·28·30·32·34열이 없다. 이 결번과 의도된 좌석 각도 변화로 생기는 시각적 빈틈은 다른 문제다. 전자는 보존하고 후자는 단·좌석의 공통 꺾임선으로 수정한다.
- 좌우 B 블록의 열별 수량이 다른 사례는 자동으로 오류가 아니다. 각각의 원본 번호 구간을 유지한다.
- 공식 도면 숫자 정렬을 추측하던 점검 코드가 A25·D26의 좌석 1번을 마지막 열 번호와 혼동했다. 이 두 건은 원본 표기에 맞춰 점검 코드만 수정했다.
- C/S와 일부 특수석은 같은 수준의 상세 개별 원장을 확보하지 못했다. 사용자 지정 삭제 D01·D51·F11은 별도 예외로 기록한다.

## 3D 위치·높이와 번호 검증의 구분

모델의 번호 집합이 PDF와 일치하는 것은 **전사·누락 검사 결과**이며 실제 현장과의 3D 일치율이 아니다. 익사이트석 형태는 공식 개수 예상도, 공식 360°와 실사 사진으로 따로 보정한다. 홈 쪽 좌석 열은 위 1층 좌석 열과 평행하게 만들고, 폴 쪽 펜스는 A03 방향 터널 문짝의 바깥 경첩에 붙인다.

공개 360°의 위치를 홈·마운드 추정점으로 모델에 대략 정렬해 A/B의 단 높이를 비교했다. 바닥 추정이 명백히 잘못된 스캔은 제외했다. A층 표본 183개의 높이 잔차 중앙값은 보정 전 약 0.92m에서 보정 후 약 0.29m로 줄었다. 촬영점 오프셋·평면 정렬 오차·바닥 추정이 섞인 수치이므로 ‘실측 오차 29cm’ 또는 정확도 백분율로 해석하지 않는다. A층 앞 단과 A/B 연결부의 과도한 높이를 조정하는 보조 근거로 사용했다.
