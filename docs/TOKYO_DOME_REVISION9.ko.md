# 도쿄돔 9차 검수

- [x] 필드 전체에 청록빛 초록색 공연용 고무판 적용
- [x] 무광 표면, 약한 입자 질감과 낮은 이음새로 고무판 표현
- [x] 포수 뒤 좌우의 관객 없는 맨 앞 단을 바로 뒤 좌석 바닥 높이까지 채움
- [x] 둥글게 정리한 패딩 펜스와 첫 단 사이에 남은 바닥 틈을 닫음
- [x] 좌우 근접·위쪽 시점과 필드 전체·바닥 근접·재생 시점 검수
- [x] 실제 충돌 바닥, 좌석 지지, 기존 통로 회귀 검사와 앱 빌드 확인

기존 회색 필드 보호판을 도쿄돔 전용 고무판 재질로 교체한다. 약 2×8m 판을 엇갈리게 배치한 이음새와 적은 색 편차를 사용한다. 일반 도쿄돔과 360도 모드가 같은 필드 재질을 사용한다.

포수 뒤 바닥의 낮은 빈 단 11곳을 인접한 첫 좌석 단 높이(약 1.518~1.702m)에 맞춘다. 패딩의 부드러운 곡선과 좌석 바닥 사이에 남은 틈도 각 단에 가까운 높이의 닫힌 바닥으로 채운다. 좌석 위치·번호는 유지한다.

검수: 좌우 바닥 높이·필드 보행 바닥을 포함한 실제 앱 검사 198개, 독립 좌석·바닥·기둥 감사, 모서리·벽 연결 검사와 구조 회귀 검사 7개 통과. 앱 빌드 통과. 6개 시점을 확인했으며 재생 시점은 실제 공연 API로 객석 조명 0, chorus 상태에서 촬영했다.
