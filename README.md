# Song2Concert

**[→ 바로 사용하기](https://fearnot502.github.io/Song2Concert/)** · 설치 없음 · 회원가입 없음 · 파일은 서버로 올라가지 않음

내 음원을 실제 공연장에서 듣는 것처럼 들려주는 웹 앱입니다. FLAC이나 WAV를 끌어다 놓고 공연장을 고르면, 그 공간의 음향을 계산해 음원에 입혀서 들려줍니다. 눈앞에는 그 공연장의 객석에서 무대를 바라보는 3D 장면이 실시간으로 펼쳐집니다.

플러그인의 "Large Hall" 프리셋이 아닙니다. **실제 건물의 치수와 벽 재질에서 음향을 계산합니다.** 도쿄 돔이 웅웅거리는 것도, 빈야드 콘서트홀이 따뜻한 것도, 웸블리가 의외로 건조한 것도 전부 그렇게 나온 결과입니다.

## 어떻게 쓰나

1. **음원을 올립니다.** 화면 가운데 버튼에 파일을 끌어다 놓거나 클릭해서 고릅니다. 여러 개를 한꺼번에 올리면 재생 큐가 만들어집니다.
2. **공연장을 고릅니다.** 상단 메뉴나 `V` 키로 여섯 곳 중 하나를 선택합니다. 재생 중에 바꿔도 소리가 끊기지 않고, 떠나는 공연장의 잔향이 울려 나가는 동안 새 공연장이 올라옵니다.
3. **자리를 조정합니다.** 웻 슬라이더는 이펙트 양이 아니라 **객석에서의 거리**입니다. 밀면 뒤로 물러나 공간이 커지고, 당기면 무대 앞으로 갑니다.
4. **내보냅니다.** 들은 그대로를 FLAC으로 저장할 수 있습니다. 원본의 비트 심도와 샘플레이트를 그대로 유지합니다.

곡이 끝나면 큐의 다음 곡으로 넘어가고, 이때도 **앞 곡의 잔향이 공연장에 남아 있는 채로** 다음 곡이 시작합니다. 실제 공연이 그렇습니다.

잠금화면과 헤드폰 버튼, 차량 오디오 컨트롤에서도 재생을 조작할 수 있고, 탭을 다른 곳으로 옮겨도 음악은 계속됩니다.

| 키 | 동작 |
| --- | --- |
| `Space` | 재생 / 일시정지 |
| `←` `→` | ±5초 탐색 |
| `F` | 파일 선택 |
| `V` | 공연장 선택 |
| `Esc` | 닫기 |

## 여섯 공연장

공연장마다 **좌석이 정해져 있습니다.** 클럽·극장·콘서트홀은 평론가가 찾아가는 명당이고, 아레나·돔·스타디움은 **FOH(콘솔) 자리** — 타협이 아니라 공연이 실제로 그 지점에서 제대로 들리도록 믹스되는 위치입니다.

| 공연장 | 좌석 | 부피 | 잔향 | 따뜻함 | 첫 반사 | 무대까지 |
| --- | --- | --- | --- | --- | --- | --- |
| **Club** | 300 | 672 m³ | 0.75초 | 0.85 타이트 | +6 ms | 4 m |
| **Theater** | 3,000 | 15,000 m³ | 1.28초 | 1.01 중립 | +16 ms | 14 m |
| **Concert Hall** 빈야드 | 2,000 | 22,000 m³ | 2.02초 | **1.20 따뜻** | +12 ms | 13 m |
| **Arena** | 22,500 | 400,000 m³ | 2.64초 | 1.14 따뜻 | +44 ms | 36 m |
| **Dome** | 45,000 | 1,240,000 m³ | **3.63초** | **1.50 따뜻** | +84 ms | 56 m |
| **Stadium** | 90,000 | 1,139,100 m³ | 2.15초 | 1.18 따뜻 | +112 ms | 66 m |

이 숫자들은 **적어 넣은 값이 아니라 계산되어 나온 값입니다.** 벽 재질 한 줄을 바꾸면 잔향도 3D 장면도 함께 움직입니다.

**따뜻함**(저역이 중역보다 얼마나 오래 울리는지)이 이 표에서 가장 많은 걸 말합니다. 콘서트홀 1.20 — 저역이 더 오래 남고, 그게 "따뜻한 홀"의 정체입니다. 흡음의 대부분을 담당하는 관객이 125 Hz에서 1 kHz의 절반밖에 흡수하지 않기 때문에 물리적으로 그렇게 됩니다. 우드 패널을 두른 클럽은 반대로 0.85, 타이트합니다.

**Stadium이 Dome보다 건조합니다.** 부피는 비슷한데(114만 vs 124만 m³) 잔향은 절반입니다 — 웸블리는 피치 위가 열려 있어서 위로 나간 소리가 돌아오지 않습니다.

**Dome은 웅웅거립니다.** 도쿄 돔의 평판을 흉내 낸 게 아니라, 124만 m³라는 크기와 가벼운 에어돔 지붕이 저역을 거의 흡수하지 못한다는 사실에서 그대로 나옵니다.

대형 3개의 형상은 사이타마 슈퍼 아레나 · 도쿄 돔 · 웸블리 스타디움에서 가져왔습니다.

## 왜 다르게 들리나

- **공연장을 형상으로 기술합니다.** 잔향 시간, 감쇠, 밀도 같은 설정값이 없습니다. 치수와 벽 재질만 적으면 나머지는 계산됩니다.
- **초기 반사가 방향을 가집니다.** 벽·천장·바닥에서 오는 반사 하나하나에 실제 도달 시간과 방향이 있고, 양귀 시간차와 머리 그림자를 거쳐 렌더됩니다. 방이 앞이 아니라 **주위에** 있게 만드는 단서입니다.
- **좌우가 다른 방을 지납니다.** 4채널 트루 스테레오 컨볼루션이라 믹스의 왼쪽과 오른쪽이 각각 좌·우 음원 위치의 공간 응답을 거칩니다.
- **큰 방이 실제로 크게 들립니다.** 잔향 레벨을 정규화하지 않아서, 반사음은 그 좌석에서 직접음보다 정말로 그만큼 아래에 있습니다. 큰 공연장이 단지 잔향이 긴 게 아니라 크게 들리는 이유입니다.
- **대형 공연장에는 딜레이 타워가 있습니다.** 실제 공연처럼 객석 사이에 세운 스피커가 몇 밀리초 늦게, 좌우가 서로 다른 시각에 도착합니다. 아레나가 감싸이는 느낌을 주는 건 거의 이것 때문입니다.
- **75 dB로 듣는 걸 보정합니다.** 공연장은 100 dB, 헤드폰은 75 dB입니다. 등청감 곡선은 평행하지 않아서 조용히 들으면 저역이 먼저 빠집니다. 집에서 듣는 공연 실황이 얇게 들리는 진짜 이유이고, 그만큼을 되살립니다.
- **이어폰에서 소리가 머리 안에 갇히지 않게 합니다.** 700 Hz 아래로 하드팬된 성분은 실제 머리가 만들 수 없는 단서입니다. 중앙(보컬·킥·베이스)은 건드리지 않고 그 부분만 정리합니다.
- **보이는 공간이 들리는 공간입니다.** 3D 장면의 치수·무대 위치·좌석이 전부 음향 계산과 같은 데이터에서 나옵니다.

## 지원

**음원 형식** — FLAC · WAV · AIFF는 무손실 경로로 디코드합니다(24bit 하이레즈 포함). MP3 · M4A · OGG도 재생됩니다. 내보내기는 FLAC 16/24bit.

**브라우저** — Chrome · Edge · Firefox · Safari. 데스크톱과 모바일 모두 지원하고, 화면 크기에 따라 레이아웃이 바뀝니다.

**개인정보** — 음원은 **전부 브라우저 안에서** 처리됩니다. 업로드도, 서버도, 계정도 없습니다. 탭을 닫으면 아무것도 남지 않습니다.

**헤드폰을 권합니다.** 방향 단서와 크로스피드가 헤드폰·이어폰을 기준으로 설계되어 있습니다.

샘플 음원은 포함되어 있지 않습니다. 직접 파일을 올려야 합니다.

## 검증

공간 응답을 합성해서 쓰기 때문에 A/B할 실측 자료가 없습니다. 그래서 귀로 상수를 돌리는 대신 **측정합니다.** 음향 전문가가 실제 홀에서 재는 것과 같은 값(옥타브별 잔향 시간, 저역비, 첫 반사 시각, 측면 반사 비율, 명료도, 양귀 상관도)을 계산해 명공연장 기준값과 대조합니다.

```bash
npm run verify
```

이 스크립트들이 잡아낸 것들 중 일부 — 리미터가 스레숄드보다 34 dB 아래에서 11.6 dB를 누르고 있던 것, 저역이 중역의 감쇠 속도를 끌고 가 도쿄 돔 잔향이 3.6초 대신 4.9초로 합성되던 것, 관객석 반사를 거울로 취급해 반대편 스탠드에서 슬랩백이 돌아오던 것, 130만 m³ 돔에 물리적으로 불가능한 3.4초를 적어두었던 것.

## 직접 실행하기

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run verify   # 음향 모델 · 합성 결과 · 브라우저 실렌더 검증
```

`main`에 push하면 GitHub Actions가 빌드해서 Pages로 배포합니다.

음향 계산(`src/audio/roomacoustics.js` · `venuerooms.js` · `impulse.js` · `binaural.js`)은 Web Audio 의존성 없는 순수 함수라 Node에서 그대로 측정할 수 있습니다. 검증 스크립트가 성립하는 이유이고, 공연장을 새로 추가하려면 `venuerooms.js`에 치수와 재질을 적는 것으로 시작하면 됩니다.

React 18 · Vite 6 · Tailwind CSS 3 · three.js · Web Audio API
